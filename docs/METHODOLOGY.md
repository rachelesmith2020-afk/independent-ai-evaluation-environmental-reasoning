# Methodology

## Benchmark structure

The evaluation used a controlled source pack combining primary case evidence, official/statutory material, peer-reviewed scientific evidence and reasoned inference. The benchmark and scoring criteria were fixed before model outputs were scored.

## Run conditions

- Models: Microsoft Copilot Auto and Google Gemini 3.1 Pro
- Fresh chat for each controlled run
- Prompts 1–10: browsing/search prohibited
- Prompts 11–12: live web research required
- Earlier pilot or invalidated runs were preserved separately but excluded from the paired score totals

## Blind scoring

Each response was stored before scoring and labelled RESPONSE X or RESPONSE Y without model identity.

Each prompt was scored out of 100:

| Criterion | Weight |
|---|---:|
| Factual accuracy | 25 |
| Evidence / citation discipline | 15 |
| Reasoning quality | 15 |
| Uncertainty calibration | 10 |
| Local-vs-general distinction | 10 |
| Management / legal precision | 10 |
| Environmental nuance | 10 |
| Writing / instruction following | 5 |

Deductions were tied to specific source or benchmark failures. Model identity was revealed only after scoring was locked.

## Core evaluation principles

Strong responses were expected to preserve source provenance, respect spatial scale, preserve modal and conditional language, separate mechanism from attribution, distinguish administrative status from measured ecological harm, treat uncertainty as information, and avoid inventing precision where evidence was incomplete.
